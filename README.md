## 🌟 The Problem
College and university students face a severe health dilemma:
- **Sedentary Desk Bound Life**: Long coding/study sessions lead to slouching ("tech neck"), back pain, and low energy.
- **Dorm & Budget Constraints**: Hostel rooms are tiny with zero gym gear; personal trainers and gym memberships are unaffordable.
- **Hostel Mess Food Realities**: High carb, low protein meals with zero easy tracking tailored to Indian college menus.
- **Exam Burnout**: Elevated cortisol, eye fatigue, and inconsistent sleep cycles.

---

## 💡 The Solution: FitMitra
**FitMitra** (*Mitra = Friend / Companion*) turns any dorm room into an intelligent, interactive personal fitness studio and wellness sanctuary:

1. **🤖 AI Vision Pose & Rep Coach**:
   - In-browser computer vision via laptop/phone webcam.
   - Real-time repetition counting for Squats, Pushups, and Jumping Jacks.
   - Vector joint angle calculation with real-time **voice coaching** cues (*"Go deeper!"*, *"Rep 5 completed!"*).
   - 100% private: Zero video frames leave the browser.
2. **🪑 Study Posture Sentinel & Pomodoro Fitness**:
   - Detects slouching and forward head craning during study marathons.
   - Built-in 25/50m study timer with automated 2-minute micro-stretches for spinal relief.
3. **🍛 Hostel Mess Smart-Logger & ₹100 Budget Protein Guide**:
   - Preloaded Indian college mess foods (Roti, Dal, Rajma-Chawal, Paneer, Boiled Eggs, Maggi).
   - Practical budget hacks to hit 70g+ protein under ₹100/day as a student (Sattu, roasted chana, soya chunks).
4. **🔥 Campus Gamification & Squad Battles**:
   - FitCoins, XP levels, daily streak flames, and Hostel Wing leaderboards (Wing A vs Wing B).
   - Daily student quests for consistent habits.
5. **🧘 Exam Stress & Mind-Body Reset**:
   - Interactive 4-7-8 Box Breathing visualizer for exam anxiety.
   - Hydration logger (250ml/500ml quick-add) and 20-20-20 eye strain reminder.

## 🛠️ Quick Start

```bash
# Clone the repository
git clone https://github.com/zero-cuser/fitmitra.git
cd fitmitra

# Install dependencies (on Windows use npm.cmd)
npm install

# Start development server
npm run dev
```
